🏰 Bolonha e MilanoProjeto de Estratégia Econômica Medieval desenvolvido em Java orientado a objetos para a avaliação do 4º Bimestre.  

📜 Sobre o JogoO jogo simula a gestão de cidades-Estado italianas (Bolonha, Milano, Florença e Veneza) a partir do ano de 1400. 
O grande objetivo dos governantes é gerenciar a agricultura, o mercado, os impostos, o exército e as construções para acumular prestígio e subir de 
título — indo de Cavaleiro até Rei/Rainha — antes do fim de 1410.   

🚀 Como Compilar e ExecutarAbra o seu terminal na pasta do código-fonte (src/bolonhaemilano) e execute os comandos abaixo:  
javac *.java
java Main
java Testes

✨ Melhorias Extras ImplementadasLimpeza de Tela: O menu limpa automaticamente a tela a cada ciclo, mantendo o ano e a vez do jogador sempre visíveis no topo.   
Pausa Interativa: O sistema aguarda o usuário pressionar ENTER para continuar, evitando que as mensagens sumam rapidamente da tela.   

📂 Estrutura do Repositóriosrc/bolonhaemilano/ — Código-fonte completo em Java (incluindo a classe Testes.java).   uml/ — Diagrama de Classes final e Diagrama de Sequência.   casos-de-uso/ — Diagrama de Casos de Uso do sistema.
